Buffin Personal Library • Site Plan WDD231

Site Name & Logo

Site Name: Buffin Personal Library

The site will act as a digital catalog for searching, saving, and managing books. The logo will use a simple book icon alongside the name for clarity. (You can replace the icon later when you choose your final artwork.)

Site Purpose

This website lets users search for books using the Open Library API, view details, and save them to a personal library. It also includes a manual add-book form with fields aligned to your Buffin Library schema (Title, Author, ISBN, Publisher, Year, Genre, Format, Location, Notes, Rating).

Target Audience & Scenarios

Audience

  • Readers who want to organize personal collections.
  • Students demonstrating contemporary web development skills.
  • Anyone who needs a lightweight, searchable book list.

Scenarios

  • Search by title or author and view results with covers, authors, and years.
  • Save results to a personal library; mark favorites; filter by author/year.
  • Manually add a book that isn’t available via the API.

Color Scheme

Light Blue #b3d9ff
Black #000000
Orange #ff9933

Light blue provides an open, welcoming canvas; black ensures strong readability; orange accents draw attention to actions and interactive elements.

Typography

  • Raleway — body text and general UI (modern, readable).
  • Cormorant Infant — headings/navigation/brand (bookish serif contrast).

Include the Google Fonts import in your main stylesheet or HTML head. Use fallbacks like Arial, sans-serif and serif.

About (about.html)

Technical Notes

  • Semantic HTML structure with responsive navigation.
  • Open Library Fetch API with async/await and try...catch.
  • Dynamic rendering of 15+ book items (card grid/list) using array methods and template literals.
  • LocalStorage for shelf, favorites, and view preferences.
  • Accessible modal dialog for book details (ESC closes, focus trap).
  • Optimized images (lazy loading for covers) to stay under ~500 kB page weight.
